# README

## What is the Obsidian Hub?

Welcome! This is an experimental vault that is maintained by the Obsidian community. It collects guides, workflows, courses, concept explainers, and showcases/templates for using Obsidian, along with the community's talks and events.

The Hub is not a directory of plugins, themes, or people. For plugins and themes, browse [community.obsidian.md](https://obsidian.md/plugins) or the in-app community plugin/theme browser instead.

For best results we recommend [downloading the current version of this vault](https://github.com/obsidian-community/obsidian-hub/archive/refs/heads/main.zip) locally and opening it in Obsidian or browsing it in our [publish site](https://publish.obsidian.md/hub).

This vault was inspired by the [awesome-obsidian](https://github.com/kmaasrud/awesome-obsidian) list.
