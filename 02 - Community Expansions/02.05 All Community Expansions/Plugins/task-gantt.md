# Task Gantt

Plugin ID: `task-gantt`
Links: [GitHub repository](https://github.com/katoiek/task-gantt) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=task-gantt)
Developed by: [[katoiek]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Manage tasks on an interactive Gantt timeline where each note is a single task. Drag bars to reschedule, link FS/SS/FF dependencies, set milestones, and edit details in a side panel.
