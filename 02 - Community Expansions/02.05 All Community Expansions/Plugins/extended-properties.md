# Extended Properties

Plugin ID: `extended-properties`
Links: [GitHub repository](https://github.com/electroluminescent/obsidian-extended-properties) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=extended-properties)
Developed by: [[electroluminescent]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A configurable properties sidebar with arrangeable sections, rich value types (sliders, colors, images, formulas, derived numbers), dice rolling, inline rolls and properties, per-type layouts, and optional modules like a D&D 5e sheet.
