# Mermaid GUI Editor

Plugin ID: `mermaid-gui-editor`
Links: [GitHub repository](https://github.com/noriyuki-lim/obsidian-mermaid-gui) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=mermaid-gui-editor)
Developed by: [[noriyuki-lim]]
Mobile compatible: [[Desktop-only plugins|No]]

Edit Mermaid diagrams — flowchart, kanban, quadrant, xychart, gantt, and more — in your notes with a GUI editor. Saves back as plain Mermaid text.
