# File Media Gallery

Plugin ID: `file-media-gallery`
Links: [GitHub repository](https://github.com/jagajaga/obsidian-file-media-gallery) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=file-media-gallery)
Developed by: [[jagajaga]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Right-click a note to view all its media (images, video, audio, PDF) as a gallery with per-type tabs and a fullscreen lightbox.
