# Right-Click Tools

Plugin ID: `right-click-tools`
Links: [GitHub repository](https://github.com/z0lw/obsidian-right-click-tools) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=right-click-tools)
Developed by: [[z0lw]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Adds Explorer right-click actions and a ribbon button to create today's date folder or note from a configurable template and move selected items to a configurable folder.
