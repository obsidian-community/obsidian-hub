# Vault Change Feed

Plugin ID: `vault-change-feed`
Links: [GitHub repository](https://github.com/kains2866/vault-change-feed) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=vault-change-feed)
Developed by: [[kains2866]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Records vault changes as a machine-readable feed with per-reader cursors, so AI assistants can incrementally catch up on what you changed.
