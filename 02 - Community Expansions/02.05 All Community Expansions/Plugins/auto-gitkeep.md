# Auto GitKeep

Plugin ID: `auto-gitkeep`
Links: [GitHub repository](https://github.com/satosprod/auto-gitkeep) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=auto-gitkeep)
Developed by: [[satosprod]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Automatically places a .gitkeep file in every folder of your vault so empty directories are tracked by Git. Scans existing folders on load and watches for new ones.
