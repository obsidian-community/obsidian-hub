# reMarkable Bridge

Plugin ID: `remarkable-bridge`
Links: [GitHub repository](https://github.com/kebl3541/obsidian-remarkable-bridge) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=remarkable-bridge)
Developed by: [[kebl3541]]
Mobile compatible: [[Desktop-only plugins|No]]

Send notes to a reMarkable as typed text, edit them there with the Type Folio, and pull the edits back. Uses the official desktop app's local store; no Connect subscription needed. Unofficial; not affiliated with reMarkable AS.
