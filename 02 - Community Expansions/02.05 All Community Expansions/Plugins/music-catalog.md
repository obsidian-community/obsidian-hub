# Music Catalog

Plugin ID: `music-catalog`
Links: [GitHub repository](https://github.com/jimparrillo/obsidian-music-catalog) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=music-catalog)
Developed by: [[jimparrillo]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Scan a CD or vinyl UPC barcode to automatically create a catalogued note with metadata and cover image, queryable via Bases.
