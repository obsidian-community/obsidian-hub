# Style Manager

Plugin ID: `style-manager`
Links: [GitHub repository](https://github.com/emarpiee/obsidian-style-manager) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=style-manager)
Developed by: [[emarpiee]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Provides advanced controls for managing themes, CSS snippets, and style settings. Transforms them into adjustable controls, enabling you to save, export or switch between configurations as presets.
