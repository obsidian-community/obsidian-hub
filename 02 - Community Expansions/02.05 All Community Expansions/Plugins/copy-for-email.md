# Copy for Email

Plugin ID: `copy-for-email`
Links: [GitHub repository](https://github.com/hwy1dot0/obsidian-copy-for-email) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=copy-for-email)
Developed by: [[hwy1dot0]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Copy selections or whole notes as email-ready rich text. Tables, callouts, code and Mermaid diagrams survive pasting into Gmail, Outlook and Apple Mail; chat apps get clean plain text.
