# Clean AI Paste

Plugin ID: `clean-ai-paste`
Links: [GitHub repository](https://github.com/goslowpoke168/obsidian-clean-ai-paste) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=clean-ai-paste)
Developed by: [[goslowpoke168]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Instantly turns messy text pasted from AI chatbots like ChatGPT, Claude, and Gemini into clean Markdown notes. Removes excessive blank lines and emojis, fixes code blocks, headers, and more.
