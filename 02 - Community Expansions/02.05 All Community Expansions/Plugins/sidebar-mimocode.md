# Sidebar MiMo-Code

Plugin ID: `sidebar-mimocode`
Links: [GitHub repository](https://github.com/allenx95/sidebar-mimocode) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=sidebar-mimocode)
Developed by: [[allenx95]]
Mobile compatible: [[Desktop-only plugins|No]]

Embeds MiMo-Code CLI Agent as an AI collaborator in your vault. Your vault becomes the working directory, giving MiMo-Code capabilities for file reads and writes, search, bash commands, and multi-step workflows.
