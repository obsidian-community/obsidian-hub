# Mark as Read

Plugin ID: `explorer-property-attributes`
Links: [GitHub repository](https://github.com/hemy301/explorer-property-attributes) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=explorer-property-attributes)
Developed by: [[hemy301]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Mark a note read or done with one click and see it in the file explorer: finished notes are grayed out with a checkmark. Any frontmatter property can style files via CSS snippets, updated instantly.
