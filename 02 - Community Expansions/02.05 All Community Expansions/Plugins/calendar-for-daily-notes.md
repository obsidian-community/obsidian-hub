# Calendar for Daily Notes

Plugin ID: `calendar-for-daily-notes`
Links: [GitHub repository](https://github.com/xryul/calendar-for-daily-notes) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=calendar-for-daily-notes)
