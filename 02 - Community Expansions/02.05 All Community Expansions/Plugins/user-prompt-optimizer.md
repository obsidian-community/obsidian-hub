# User Prompt Optimizer

Plugin ID: `user-prompt-optimizer`
Links: [GitHub repository](https://github.com/chuanqq/user-prompt-optimizer) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=user-prompt-optimizer)
Developed by: [[chuanqq]]
Mobile compatible: [[Desktop-only plugins|No]]

Select a prompt and refine it with an LLM. Two modes: template-driven structured optimization, and template-free light polishing (disambiguate / dedupe / mark missing info with placeholders).
