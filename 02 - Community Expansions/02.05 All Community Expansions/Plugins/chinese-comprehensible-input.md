# Chinese Comprehensible Input

Plugin ID: `chinese-comprehensible-input`
Links: [GitHub repository](https://github.com/davadev/obsidian_chinese_comprehensible_input) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=chinese-comprehensible-input)
