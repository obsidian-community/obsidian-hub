# Cyrillic and Non-Latin Tags

Plugin ID: `cyrillic-non-latin-tags`
Links: [GitHub repository](https://github.com/javatutor-ru/obsidian-cyrillic-non-latin-tags) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=cyrillic-non-latin-tags)
Developed by: [[javatutor-ru]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Adds custom CSS classes to tags containing any non-Latin letters (cyrillic, hieroglyphs, diacritics, etc.) in Editing view. This allows you to customize the appearance of non-Latin tags via CSS snippets and third-party plugins.
