# Yonxao Mind Map

Plugin ID: `yonxao-mindmap`
Links: [GitHub repository](https://github.com/yonxao/yonxao-mindmap) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=yonxao-mindmap)
Developed by: [[yonxao]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A feature-rich mind map plugin that renders `yxmm` code blocks as interactive SVG mind maps. Supports 20+ layouts, interactive editing, multiple themes, and rich customization options.
