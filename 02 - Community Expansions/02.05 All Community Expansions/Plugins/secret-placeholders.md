# Secret Placeholders

Plugin ID: `secret-placeholders`
Links: [GitHub repository](https://github.com/lai2301/obsidian-secret-placeholders) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=secret-placeholders)
Developed by: [[lai2301]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Embed password-manager secrets in notes as placeholders so the .md never contains the actual credential. Supports OpenBao/Vault, 1Password Connect, and Bitwarden/Vaultwarden.
