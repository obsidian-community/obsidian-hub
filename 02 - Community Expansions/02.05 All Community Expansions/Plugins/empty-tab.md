# Empty Tab

Plugin ID: `empty-tab`
Links: [GitHub repository](https://github.com/waldemar-one/obsidian-empty-tab) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=empty-tab)
Developed by: [[waldemar-one]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Adds a command to replace the current tab with an empty page, the same screen shown when opening a new tab.
