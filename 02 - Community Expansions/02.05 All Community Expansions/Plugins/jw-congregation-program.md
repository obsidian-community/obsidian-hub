# JW Convention Program

Plugin ID: `jw-congregation-program`
Links: [GitHub repository](https://github.com/realsteeldeal/obsidian-jw-congregation) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=jw-congregation-program)
Developed by: [[realsteeldeal]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Imports JW convention programs (.jwpub / RTF-ZIP) and creates structured, linked notes in your vault. Supports German, English, French, Italian, Portuguese, Russian and Spanish program files.
