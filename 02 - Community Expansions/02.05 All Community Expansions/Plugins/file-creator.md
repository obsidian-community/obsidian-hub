# File Creator

Plugin ID: `file-creator`
Links: [GitHub repository](https://github.com/dudethatserin/FileCreator) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=file-creator)
Developed by: [[dudethatserin]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Create files in specific folders with optional date prefixing/suffixing, PDF creation from templates, and Kanban board creation. Can also embed attachments in existing files.
