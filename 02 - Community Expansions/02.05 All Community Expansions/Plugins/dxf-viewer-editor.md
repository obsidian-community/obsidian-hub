# DXF Viewer and Editor

Plugin ID: `dxf-viewer-editor`
Links: [GitHub repository](https://github.com/ondreu/DXF-Viewer-and-editor) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=dxf-viewer-editor)
Developed by: [[ondreu]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

View, create, measure, draw and edit DXF drawings — ellipses, construction lines, dimensions, fillet/chamfer/trim/extend/join/break/explode, arrays, layers and precise properties — as file views and note embeds, on desktop and mobile.
