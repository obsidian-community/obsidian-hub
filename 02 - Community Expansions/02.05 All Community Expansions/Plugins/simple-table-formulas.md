# Simple Table Formulas

Plugin ID: `simple-table-formulas`
Links: [GitHub repository](https://github.com/maxcohn/obsidian-simple-table-formulas) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=simple-table-formulas)
Developed by: [[maxcohn]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Add spreadsheet-style formulas to Markdown tables. Write a formula into a cell, run a command to bake it into a computed value with the formula preserved in a comment for later editing.
