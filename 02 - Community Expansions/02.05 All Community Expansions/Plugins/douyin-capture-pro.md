# Douyin Capture Pro

Plugin ID: `douyin-capture-pro`
Links: [GitHub repository](https://github.com/zhaoyaoyuan/obsidian-douyin-capture) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=douyin-capture-pro)
Developed by: [[zhaoyaoyuan]]
Mobile compatible: [[Desktop-only plugins|No]]

Import Douyin links or pasted share text into notes with no-watermark videos, images, and captions. Add titles, topics, tags, and frontmatter. Local Whisper to Simplified Chinese; data stays on-device. Requires local Python backend (see README).
