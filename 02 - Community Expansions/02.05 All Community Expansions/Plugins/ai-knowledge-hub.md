# Vault Audit AI

Plugin ID: `ai-knowledge-hub`
Links: [GitHub repository](https://github.com/zinverno/obsidian-ai-hub) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=ai-knowledge-hub)
Developed by: [[zinverno]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

AI-powered vault audit: find orphan notes, cluster topics, get tag and link suggestions, batch-process notes with filters. Works with OpenRouter, OpenAI, Groq or locally via Ollama.
