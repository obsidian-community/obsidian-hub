# Markdown Image Manager

Plugin ID: `md-image-manager`
Links: [GitHub repository](https://github.com/ytahml/obsidian-image-manager) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=md-image-manager)
Developed by: [[ytahml]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A powerful image management plugin. Browse, optimize, upload to image hosting, and organize your images. Ideal for converting Wiki image refs to standard Markdown format.
