# Clippings Dedupe

Plugin ID: `clippings-dedupe`
Links: [GitHub repository](https://github.com/somasekimoto/obsidian-clippings-dedupe) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=clippings-dedupe)
Developed by: [[somasekimoto]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Merge duplicate highlights that Web Clipper appends when re-clipping a page, while protecting the comments you write under each quote.
