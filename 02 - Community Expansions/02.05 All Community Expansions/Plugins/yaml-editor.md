# YAML Editor

Plugin ID: `yaml-editor`
Links: [GitHub repository](https://github.com/idheitmann/obsidian-yaml-editor) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=yaml-editor)
Developed by: [[idheitmann]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A structured YAML editor with schema-aware completions, smart indentation, folding, diagnostics, inline value quoting, and a dedicated editing surface for standalone .yaml / .yml files — all without reformatting your text.
