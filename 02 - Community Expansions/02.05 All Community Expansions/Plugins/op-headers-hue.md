# Headers Hue

Plugin ID: `op-headers-hue`
Links: [GitHub repository](https://github.com/markcrobbins2112/op-headers-hue) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=op-headers-hue)
Developed by: [[markcrobbins2112]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Colors markdown headers from H1-H6, adds directional gradient borders, handles hover lightening, and plays custom hue shifts during fold state updates.
