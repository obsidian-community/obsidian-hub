# Proxmox VM List

Plugin ID: `proxmox-vm-list`
Links: [GitHub repository](https://github.com/psalkiewicz/obsidian-proxmox-vm-list) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=proxmox-vm-list)
