# Pin Board

Plugin ID: `pin-board`
Links: [GitHub repository](https://github.com/rayvven/obsidian-pin-board) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=pin-board)
Developed by: [[rayvven]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A Pinterest-style vertical scrolling board for the images and videos in a folder. Point it at a folder, scroll, and optionally attach a note to any pin.
