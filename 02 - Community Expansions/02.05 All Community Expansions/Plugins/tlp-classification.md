# TLP Classification

Plugin ID: `tlp-classification`
Links: [GitHub repository](https://github.com/rafamss/obsidian-tlp-classification) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=tlp-classification)
Developed by: [[rafamss]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Classify documents using the Traffic Light Protocol (TLP). Visual selector in the properties panel, status bar indicator, and automatic PDF header/footer badge generation for Better Export PDF.
