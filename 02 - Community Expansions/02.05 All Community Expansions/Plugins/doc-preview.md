# Doc Preview

Plugin ID: `doc-preview`
Links: [GitHub repository](https://github.com/notenerdofficial/doc-preview) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=doc-preview)
Developed by: [[notenerdofficial]]
Mobile compatible: [[Desktop-only plugins|No]]

Preview PowerPoint, Word, and Excel files. Automatically refreshes when you, Claude, or another AI agent changes the file, so your preview is always up to date. Renders via a local LibreOffice install (bring your own, or install one from Settings).
