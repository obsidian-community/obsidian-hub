# Cite Engine

Plugin ID: `cite-engine`
Links: [GitHub repository](https://github.com/flyingmiata-droid/cite-engine) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=cite-engine)
Developed by: [[flyingmiata-droid]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Catch quotes that silently went stale. When you edit a source note, Cite Engine flags any quote you pulled from it that no longer matches, so your literature notes and citations stay accurate.
