# Task Tree

Plugin ID: `task-tree`
Links: [GitHub repository](https://github.com/aldorithm392/obsidian-task-tree) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=task-tree)
Developed by: [[aldorithm392]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

See your Markdown tasks as a tree and a Kanban board at once. Break projects into nested subtasks; a parent's progress rolls up from its children. Plain Markdown, agent-ready.
