# CSS Resource Variables

Plugin ID: `css-resource-variables`
Links: [GitHub repository](https://github.com/chrisairbrown-del/CSS-Resource-Variables) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=css-resource-variables)
Developed by: [[chrisairbrown-del]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Map a local vault file (image, font, anything) to a CSS custom property, so any theme or snippet can reference your own local files with var().
