# Subtle TOC

Plugin ID: `subtle-toc`
Links: [GitHub repository](https://github.com/xupisco/obisidian-suble-toc) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=subtle-toc)
Developed by: [[xupisco]]
Mobile compatible: [[Desktop-only plugins|No]]

A floating, Capacities-style table of contents: an edge minimap for headings with active-heading tracking and click-to-scroll, plus an open-tasks tab with a live count and optional one-click completion.
