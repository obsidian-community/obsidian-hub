# Rainbow Header Coloring

Plugin ID: `rainbow-header-coloring`
Links: [GitHub repository](https://github.com/albertoos/obsidian-rainbow-header-coloring-plugin) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=rainbow-header-coloring)

Color markdown headers (H1-H6) with customizable palettes. Supports colormap cycling and per-level user-defined colors.
