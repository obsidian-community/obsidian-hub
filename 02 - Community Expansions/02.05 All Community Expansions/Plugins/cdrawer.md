# Commutative Diagram Editor

Plugin ID: `cdrawer`
Links: [GitHub repository](https://github.com/hxuanwang/obsidian-cdrawer) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=cdrawer)
Developed by: [[hxuanwang]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Insert and edit commutative diagrams on a fixed grid. Renders to SVG matching native CD styling. Export to tikz-cd and AMS CD.
