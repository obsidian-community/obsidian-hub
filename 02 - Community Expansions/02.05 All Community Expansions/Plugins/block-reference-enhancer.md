# Block Reference Enhancer

Plugin ID: `block-reference-enhancer`
Links: [GitHub repository](https://github.com/msjsc001/obsidian-block-reference-enhancer) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=block-reference-enhancer)
