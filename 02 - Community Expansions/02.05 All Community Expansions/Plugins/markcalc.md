# MarkCalc

Plugin ID: `markcalc`
Links: [GitHub repository](https://github.com/levis-code/markcalc) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=markcalc)
Developed by: [[levis-code]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Spreadsheet-style formulas in Markdown tables. Results live as plain, portable text, not a rendered view. Aggregates, lookups, dates, custom functions, and cross-note references with automatic recalculation.
