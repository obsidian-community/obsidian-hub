# PaperFolio for Kobo

Plugin ID: `paperfolio-kobo`
Links: [GitHub repository](https://github.com/fire-university/paperfolio-obsidian) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=paperfolio-kobo)
Developed by: [[fire-university]]
Mobile compatible: [[Desktop-only plugins|No]]

Import your Kobo highlights as clean Markdown notes: one note per book, sorted by true reading order and grouped by chapter, with your own notes protected. Reads from a connected Kobo eReader or the Kobo desktop app.
