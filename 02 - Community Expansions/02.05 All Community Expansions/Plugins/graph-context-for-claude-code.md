# Graph Context for Claude Code

Plugin ID: `graph-context-for-claude-code`
Links: [GitHub repository](https://github.com/senna-lang/graph-context-for-claude-code) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=graph-context-for-claude-code)
Developed by: [[senna-lang]]
Mobile compatible: [[Desktop-only plugins|No]]

Claude Code's /ide, with your knowledge graph attached. Select text and it's pushed to Claude with the graph expanded: embeds inlined, linked notes summarized, heading path and backlinks. Zero config, no extra server.
