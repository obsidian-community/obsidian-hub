# Paste Image as WebP

Plugin ID: `paste-image-as-webp`
Links: [GitHub repository](https://github.com/cocoaai-it/paste-image-as-webp) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=paste-image-as-webp)
Developed by: [[cocoaai-it]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Paste images as compressed WebP files when pasting from the clipboard, with customizable file names, quality settings, and save locations.
