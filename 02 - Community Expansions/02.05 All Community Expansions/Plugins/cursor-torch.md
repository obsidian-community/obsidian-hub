# Cursor Torch

Plugin ID: `cursor-torch`
Links: [GitHub repository](https://github.com/astraaaa02/Obsidian-Torch-Cursor) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=cursor-torch)
Developed by: [[astraaaa02]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Turns the text cursor into a flickering torch: a warm glow lights the text around the caret while the rest of the note fades into darkness.
