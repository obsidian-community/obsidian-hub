# Wayfinder Maps

Plugin ID: `wayfinder-maps`
Links: [GitHub repository](https://github.com/ocuclaw/obsidian-wayfinder) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=wayfinder-maps)
Developed by: [[ocuclaw]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Visualizes wayfinder maps (from Matt Pocock's skills workflow) as dependency-layered ticket trees from GitHub issues, with frontier highlighting and one-click /wayfinder command copying.
