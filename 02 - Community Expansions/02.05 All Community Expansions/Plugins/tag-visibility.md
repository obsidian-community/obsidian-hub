# Tag Visibility

Plugin ID: `tag-visibility`
Links: [GitHub repository](https://github.com/prisant-labs/obsidian-tag-visibility) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=tag-visibility)
Developed by: [[prisant-labs]]

Hide, flag, or always-show any tag across the tag pane, Properties, autocomplete, and Notebook Navigator. Display-only, file-safe, fully reversible.
