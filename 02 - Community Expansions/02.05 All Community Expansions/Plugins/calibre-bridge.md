# Calibre Bridge

Plugin ID: `calibre-bridge`
Links: [GitHub repository](https://github.com/p24l/calibre-bridge) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=calibre-bridge)
Developed by: [[p24l]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Import books from a Calibre Content Server as Markdown notes with structured frontmatter, cover images, and descriptions. Reading status and personal notes are preserved across re-imports.
