# LLM Translate

Plugin ID: `llm-translate`
Links: [GitHub repository](https://github.com/chenyuxiaojin/obsidian-llm-translate) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=llm-translate)
Developed by: [[chenyuxiaojin]]
Mobile compatible: [[Desktop-only plugins|No]]

Translate selected text or full notes using DeepSeek, OpenAI, Gemini, and other OpenAI-compatible LLM providers. Preserves YAML frontmatter and supports streaming with cancellation.
