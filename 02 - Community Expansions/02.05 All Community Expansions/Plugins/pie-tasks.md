# Pie Tasks

Plugin ID: `pie-tasks`
Links: [GitHub repository](https://github.com/pieofmind/pie-task-plugin-obsidian) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=pie-tasks)
Developed by: [[pieofmind]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Manage tasks from Markdown files across multiple boards. Switch task files instantly and view them as a board, list, calendar, or dashboard, with checkboxes written straight back to the file.
