# PDF Image Extractor

Plugin ID: `pdf-image-extractor`
Links: [GitHub repository](https://github.com/svew/obsidian-pdf-image-extractor) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=pdf-image-extractor)
Developed by: [[svew]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Adds a command to extract embedded images from the currently open PDF and save them to your vault's attachments folder.
