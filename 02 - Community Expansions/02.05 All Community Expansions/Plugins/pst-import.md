# PST Import

Plugin ID: `pst-import`
Links: [GitHub repository](https://github.com/wenciara/obsidian-pst-importer) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=pst-import)
Developed by: [[wenciara]]
Mobile compatible: [[Desktop-only plugins|No]]

Import Outlook PST email archives as Markdown files with metadata, attachments, and wikilinks. Supports PST files of any size (including >2GB Unicode PST) via pure JavaScript.
