# Easy Wikilink

Plugin ID: `easy-wikilink`
Links: [GitHub repository](https://github.com/rockorolla/obsidian-easy-wikilink) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=easy-wikilink)
Developed by: [[rockorolla]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Works like Ctrl+K but for internal wikilinks. Select text, pick a page, generates [[page|selected text]].
