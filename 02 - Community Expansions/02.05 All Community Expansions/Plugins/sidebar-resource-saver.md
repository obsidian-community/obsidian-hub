# Sidebar Resource Saver

Plugin ID: `sidebar-resource-saver`
Links: [GitHub repository](https://github.com/kjh-portfolio/202606-sidebar-resource-saver) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=sidebar-resource-saver)
