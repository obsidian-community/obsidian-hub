# Browser Bookmark

Plugin ID: `browser-bookmark`
Links: [GitHub repository](https://github.com/notenerdofficial/browser-bookmark) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=browser-bookmark)
