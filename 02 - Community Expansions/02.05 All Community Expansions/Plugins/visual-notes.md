# Visual Notes

Plugin ID: `visual-notes`
Links: [GitHub repository](https://github.com/danderson1988/visual-notes) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=visual-notes)
Developed by: [[danderson1988]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A visual workspace built on the Canvas format: nestable freeform boards, icon tile grids, kanban boards, sticky notes, checklists, columns, drawing with pen and highlighter, labels, reactions, and more.
