# Glossary Linker

Plugin ID: `glossary-linker`
Links: [GitHub repository](https://github.com/max-fluff/obsidian-glossary-linker) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=glossary-linker)
Developed by: [[max-fluff]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Highlights glossary terms in any word form, turns them into real links, and learns new aliases from links you already made.
