# Anatomed 3D Anatomy

Plugin ID: `anatomed`
Links: [GitHub repository](https://github.com/pitfa19/anatomed-obsidian) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=anatomed)
Developed by: [[pitfa19]]
Mobile compatible: [[Desktop-only plugins|No]]

Embed interactive, region-isolated 3D anatomy in your notes. Write a region in an anatomed code block to get a rotatable, validated 3D model with a toggleable legend.
