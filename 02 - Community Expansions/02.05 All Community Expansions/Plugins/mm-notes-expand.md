# MM Notes Expand

Plugin ID: `mm-notes-expand`
Links: [GitHub repository](https://github.com/lemathmath/Obsidian_MM-Notes-Expand) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=mm-notes-expand)
Developed by: [[lemathmath]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Expanded controls for canvas. Clicking on a note or card creates an overlay in which all the content of that node can be read. Double-clicking on a note opens it in a new tab for editing.
