# Gallery View

Plugin ID: `gallery-view`
Links: [GitHub repository](https://github.com/mkshp-dev/obsidian-gallery-plugin) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=gallery-view)
Developed by: [[mkshp-dev]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Create interactive image galleries in your notes using obs-gallery code blocks. Supports multiple view types (thumbnail, carousel, grid) and both local vault images and external URLs.
