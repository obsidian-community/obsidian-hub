# WikiFlash

Plugin ID: `wikiflash`
Links: [GitHub repository](https://github.com/paolinpaperin/obsidian-wikiflash) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=wikiflash)
Developed by: [[paolinpaperin]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Flashes a wikilink's [[ ]] brackets when you create one or move the cursor inside it — an Xcode-style brace-match cue. Fully colour-customizable.
