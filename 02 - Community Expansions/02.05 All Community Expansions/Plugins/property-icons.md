# Property Icons

Plugin ID: `property-icons`
Links: [GitHub repository](https://github.com/runnerback/property-icons) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=property-icons)
Developed by: [[runnerback]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Show badge icons before file names in the explorer based on note property (frontmatter) rules. Configure multiple rule groups with AND/OR conditions, each mapped to a built-in brand icon or your own uploaded image.
