# Scan to Markdown

Plugin ID: `scan-to-markdown`
Links: [GitHub repository](https://github.com/bwtymdb/scan2md) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=scan-to-markdown)
Developed by: [[bwtymdb]]
Mobile compatible: [[Desktop-only plugins|No]]

用手机扫码拍照，经 LLM 视觉模型把书本/公式/表格内容转成 Markdown，直接写入当前笔记光标处或另存为新笔记.
