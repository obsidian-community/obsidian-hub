# ZoyClip - Note to Short Video

Plugin ID: `zoyclip`
Links: [GitHub repository](https://github.com/zoyluoblue/obsidian-note-to-video) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=zoyclip)
Developed by: [[zoyluoblue]]
Mobile compatible: [[Desktop-only plugins|No]]

Turn a note into a 9:16 vertical short video. A cloud LLM (OpenAI/DeepSeek) rewrites it into a script; local Kokoro TTS and ffmpeg render it with auto images, captions and music. Your note text is sent to the cloud LLM.
