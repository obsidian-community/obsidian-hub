# Third-party Sync

Plugin ID: `third-party-sync`
Links: [GitHub repository](https://github.com/nightfall-yl/obsidian-third-party-sync) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=third-party-sync)
Developed by: [[nightfall-yl]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Security and feature updates for the remotely-save unofficial plugin allowing users to synchronize notes between local device and the cloud service. Not backwards compatible.
