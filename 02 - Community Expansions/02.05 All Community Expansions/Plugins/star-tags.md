# Star Tags

Plugin ID: `star-tags`
Links: [GitHub repository](https://github.com/sajee05/obsidian-star-tags) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=star-tags)
Developed by: [[sajee05]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Scans your entire vault for customizable tags (like #todo) and lists them with context in an interactive sidebar panel. Features visual checkboxes specifically for #todo tags.
