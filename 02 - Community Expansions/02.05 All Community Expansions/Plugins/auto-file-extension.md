# Auto File Extension

Plugin ID: `auto-file-extension`
Links: [GitHub repository](https://github.com/sec-ml/obsidian-auto-file-extension) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=auto-file-extension)
Developed by: [[sec-ml]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Automatically change file extensions based on a trickle-down ruleset. Rules can match directory path, file content (using RegEx), or both.
