# Note Calendar

Plugin ID: `note-calendar`
Links: [GitHub repository](https://github.com/is-ming/obsidian-note-calendar) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=note-calendar)
Developed by: [[is-ming]]

A calendar plugin that displays lunar dates, holidays, workday adjustments, solar terms, and allows updating/creating notes associated with calendar entries.
