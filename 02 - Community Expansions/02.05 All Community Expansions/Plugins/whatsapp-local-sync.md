# WhatsApp Local Sync

Plugin ID: `whatsapp-local-sync`
Links: [GitHub repository](https://github.com/nabheetcloud/Obsidian-Whatsapp) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=whatsapp-local-sync)
Developed by: [[nabheetcloud]]
Mobile compatible: [[Desktop-only plugins|No]]

Read your local WhatsApp Desktop message database and mirror chats into your vault as one transcript note per conversation. Read-only, incremental, fully local — no network, no cloud, no API keys.
