# Folder Base View

Plugin ID: `folder-base-view`
Links: [GitHub repository](https://github.com/kulysocc/obsidian-folder-base-view) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=folder-base-view)
Developed by: [[kulysocc]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]
