# Rollup to PDF

Plugin ID: `rollup-to-pdf`
Links: [GitHub repository](https://github.com/svm0n/obsidian-rollup-to-pdf) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=rollup-to-pdf)
Developed by: [[svm0n]]
Mobile compatible: [[Desktop-only plugins|No]]

Compile a tree of wiki-linked notes into a single formatted PDF via Pandoc, with heading-relative nesting and inline or appendix-style page expansion.
