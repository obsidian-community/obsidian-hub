# Random Task Selector

Plugin ID: `random-task-selector`
Links: [GitHub repository](https://github.com/jaidetree/obsidian-random-task) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=random-task-selector)
Developed by: [[jaidetree]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Randomly draws a task from the checklist at your cursor and stamps tasks with selected-at / completed-at datetimes.
