# Paste ASCII Table

Plugin ID: `paste-ascii-table`
Links: [GitHub repository](https://github.com/arkounay/obsidian-paste-ascii-table) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=paste-ascii-table)
Developed by: [[arkounay]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Turns box-drawing and ASCII art tables from terminal output into real Markdown tables when you paste them, rejoining cells the terminal wrapped over several lines.
