# Folder to Tag

Plugin ID: `folder-to-tag`
Links: [GitHub repository](https://github.com/merijnvervoorn/obsidian-folder-to-tag) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=folder-to-tag)
Developed by: [[merijnvervoorn]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Automatically adds or updates a tag based on the folder a note is in. Updates both on creation and file move.
