# TaskNotes Agenda Wrapper

Plugin ID: `tasknotes-agenda-wrapper`
Links: [GitHub repository](https://github.com/toya-co/tasknotes-agenda-wrapper) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=tasknotes-agenda-wrapper)
Developed by: [[toya-co]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A simple, styled Today's Agenda window for TaskNotes — stats, a date-grouped list, and quick task entry, for a sidebar pane or embedded in a note.
