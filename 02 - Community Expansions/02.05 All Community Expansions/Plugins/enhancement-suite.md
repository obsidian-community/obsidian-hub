# Enhancement Suite

Plugin ID: `enhancement-suite`
Links: [GitHub repository](https://github.com/lemon695/obsidian-enhancement-suite) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=enhancement-suite)
Developed by: [[lemon695]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Bundle many editing helpers into one plugin: table sorting, YAML tools, export, search and replace, JSON and base viewers, word count, footnotes, callouts, reading progress, rename, clipboard copy, and terminal launch.
