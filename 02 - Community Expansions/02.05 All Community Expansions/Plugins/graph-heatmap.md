# Graph Heatmap

Plugin ID: `graph-heatmap`
Links: [GitHub repository](https://github.com/mafgin/obsidian-graph-heatmap) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=graph-heatmap)
Developed by: [[mafgin]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Color graph view nodes by recency, connectedness, word count, or file size. Range slider, Focus Mode (orphans/hubs/stale), recency marker, palettes, and background/connection color — all from an in-graph panel.
