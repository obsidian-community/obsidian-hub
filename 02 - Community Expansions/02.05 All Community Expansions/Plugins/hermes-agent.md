# Hermes Agent

Plugin ID: `hermes-agent`
Links: [GitHub repository](https://github.com/jsun2020/hermes-agent-obsidian-plugin) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=hermes-agent)
Developed by: [[jsun2020]]
Mobile compatible: [[Desktop-only plugins|No]]

Chat with a locally installed Hermes Agent (Desktop or CLI/TUI) from your vault. Send the current note or selection to the local Hermes gateway and stream replies in a sidebar, with agent file tools and saved chat history.
