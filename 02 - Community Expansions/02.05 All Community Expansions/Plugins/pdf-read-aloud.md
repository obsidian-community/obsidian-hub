# PDF Read Aloud

Plugin ID: `pdf-read-aloud`
Links: [GitHub repository](https://github.com/gurnoorrana/Obsidian-pdf-read-aloud) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=pdf-read-aloud)
Developed by: [[gurnoorrana]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Reads open PDF files aloud using the Web Speech API. Includes play, pause, stop, skip controls, speed adjustment, voice selection, and click-to-start.
