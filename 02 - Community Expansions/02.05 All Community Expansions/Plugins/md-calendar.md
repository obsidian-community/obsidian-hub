# MD Calendar

Plugin ID: `md-calendar`
Links: [GitHub repository](https://github.com/mrrepac/obsidian-md-calendar) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=md-calendar)
Developed by: [[mrrepac]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

A calendar that lives in one Markdown note: a code block renders switchable month / week / day / agenda views — events and tasks, recurrence, colors, notes, drag-to-reschedule, keyboard control — and writes all data back into that same block.
