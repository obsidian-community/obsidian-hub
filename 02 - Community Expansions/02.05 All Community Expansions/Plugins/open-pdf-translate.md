# OPEN PDF Translate

Plugin ID: `open-pdf-translate`
Links: [GitHub repository](https://github.com/vetrenar/Open-PDF-Translate) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=open-pdf-translate)
Developed by: [[vetrenar]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Translate PDF documents with overlay, supports OpenRouter, OpenAI, Gemini, Ollama, and custom endpoints. Includes layout detection, AI OCR Vision and persistent storage of translations.
