# Copy File to Clipboard

Plugin ID: `copy-file-to-clipboard`
Links: [GitHub repository](https://github.com/ezxabi/copy-file-to-clipboard) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=copy-file-to-clipboard)
Developed by: [[ezxabi]]
Mobile compatible: [[Desktop-only plugins|No]]

Right-click any file in the file explorer to copy it to the clipboard. Configurable: text files as text or raw file, images as PNG or raw file.
