# Draw a Mermaid

Plugin ID: `draw-a-mermaid`
Links: [GitHub repository](https://github.com/yaye-work/obsidian-draw-a-mermaid) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=draw-a-mermaid)
Developed by: [[yaye-work]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Build mermaid flowcharts visually — drag blocks and connectors on a canvas, rename inline, and get live-generated mermaid code. Adds an editor to mermaid code blocks and a ribbon button.
