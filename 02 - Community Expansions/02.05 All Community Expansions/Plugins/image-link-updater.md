# Image Link Updater

Plugin ID: `image-link-updater`
Links: [GitHub repository](https://github.com/andy51002000/obsidian-image-link-updater) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=image-link-updater)
Developed by: [[andy51002000]]
Mobile compatible: [[Desktop-only plugins|No]]

Auto-repairs broken image links vault-wide on rename, move, or paste. Supports Markdown links, Cut & Paste with link updates, and OS-level move detection.
