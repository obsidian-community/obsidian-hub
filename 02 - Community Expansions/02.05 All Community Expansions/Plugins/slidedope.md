# SlideDope

Plugin ID: `slidedope`
Links: [GitHub repository](https://github.com/russquan/slidedope) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=slidedope)
Developed by: [[russquan]]
Mobile compatible: [[Desktop-only plugins|No]]

Make slide decks as single-file HTML presentations: PPTX-like editing with drag-to-reorder, inline text with a format toolbar, image paste/drag/resize, and a built-in player with fullscreen and PDF export.
