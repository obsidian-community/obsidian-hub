# Private Quartz Publish

Plugin ID: `private-quartz-publish`
Links: [GitHub repository](https://github.com/jagajaga/private-quartz-publish) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=private-quartz-publish)
Developed by: [[jagajaga]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Opt-in publish notes or whole folders to a self-hosted Quartz site. Each URL is an unguessable random slug; sharing a file link reveals only that file, sharing a folder link reveals only its bundled notes.
