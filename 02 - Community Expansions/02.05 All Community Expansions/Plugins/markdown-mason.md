# Markdown Mason

Plugin ID: `markdown-mason`
Links: [GitHub repository](https://github.com/mmomm-org/obsidian-markdown-mason) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=markdown-mason)
Developed by: [[mmomm-org]]
Mobile compatible: [[Desktop-only plugins|No]]

Reshape pasted or whole-note Markdown to fit a note's structure — heading cascade, footnote renumbering and dedup — plus a runnable, consent-gated script library.
