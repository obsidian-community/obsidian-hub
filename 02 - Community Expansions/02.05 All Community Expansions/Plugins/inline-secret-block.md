# Inline Secret Block

Plugin ID: `inline-secret-block`
Links: [GitHub repository](https://github.com/vnrtmnv/obsidian-inline-secret-block) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=inline-secret-block)
Developed by: [[vnrtmnv]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Auto-encrypt fenced secret blocks inside notes with AES-256-GCM. Multi-key passphrase support keeps passwords and tokens safe from sync, backups, and AI agents reading the vault.
