# Vault Task Planner

Plugin ID: `vault-task-planner`
Links: [GitHub repository](https://github.com/giacomoleonzi/vault-task-planner-obsidian) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=vault-task-planner)
Developed by: [[giacomoleonzi]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Aggregates all incomplete tasks from the vault into a monthly timeline view with in-place date editing and write-back to source notes.
