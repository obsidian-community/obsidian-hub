# Table Calc

Plugin ID: `table-calc`
Links: [GitHub repository](https://github.com/benruns/table-calc-plugin) or [<button id=HH>Open in Obsidian</button>](obsidian://show-plugin?id=table-calc)
Developed by: [[benruns]]
Mobile compatible: [[Mobile-compatible plugins|Yes]]

Adds formula support to markdown tables. Use =SUM(A1:A5), =AVERAGE(B1:B3), =A1*B1, etc. in any table cell.
