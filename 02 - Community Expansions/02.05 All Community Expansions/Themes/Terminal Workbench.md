## Customization Options (Style Settings Plugin) 

**Colors**: 
- Primary accent: Main prompt, active tab, and link color. Follows your Obsidian accent color until overridden here.
- Secondary accent: Used for sidebars, metadata, and quiet highlights.
- Warm accent: Used for warnings, highlights, and subtle attention.

**Layout**: 
- Editor line width: Reading and editing width in pixels.
- UI radius: Corner radius for controls and panes.
- Compact workspace: Tightens sidebars, tabs, and headers.
- Soft neon highlights: Adds a restrained glow to active elements.
- Active-line prompt marker: Shows a small terminal prompt beside the active editor line.

**Fonts**: 
- Editor font
- UI font
- Code font

**File explorer**: 
- Colored folders: Gives each top-level folder its own color from the six below, cycled by order; every subfolder and note inside inherits its top folder's color.
- Folder color 1
- Folder color 2
- Folder color 3
- Folder color 4
- Folder color 5
- Folder color 6
- File name color

**Headings**: 
- Neutral heading colors: Uses the normal text color for H2-H4 instead of the accent colors.
- Hide heading underline rules: Removes the fading rule below H1 and H2.

**Editor**: 
- Hide active line highlight: Removes the tinted background and accent bar on the active editor line.
- Hide blockquote marker: Removes the ">" glyph at the start of blockquotes.
- Text line height

**Code blocks**: 
- Hide code block header band: Removes the header strip and glyph, leaving a plain framed block.

**Workspace chrome**: 
- Plain tab titles: Interface font tab titles instead of uppercase monospace.
- Plain breadcrumb: Interface font note path instead of the monospace shell style.

**Tasks and tags**: 
- Neutral task states: Cancelled, deferred, and important tasks use the standard checkbox color.
- Tag shape

**Mermaid**: 
- Stock Mermaid diagrams: Disables the theme's diagram styling and uses Obsidian's defaults.

**Callout colors**: 
- Recolor callouts: Pick a palette color for each callout type. Aliases follow their base type (for example, hint follows Tip, and caution follows Warning).
- Note callout
- Abstract / Summary callout
- Info callout
- Todo callout
- Tip / Hint callout
- Important callout
- Success / Done callout
- Question / Help callout
- Warning / Caution callout
- Failure / Missing callout
- Danger / Error callout
- Bug callout
- Example callout
- Quote / Cite callout
