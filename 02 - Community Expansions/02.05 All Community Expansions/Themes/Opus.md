## Customization Options (Style Settings Plugin) 

**Palette**: 
- Flavor: The palette family. Prima Materia (cool slate / warm latte) is the default; Nigredo is stark true-black; Citrinitas is warm and cozy (Gruvbox-spirited, one accent). Each is a full, contrast-audited palette in light and dark.

**Accent**: 
- Accent color: The tempered-amber accent — drives headings, links, callouts, tabs, and the active-file rail. Teal (good) and clay (warning) stay fixed.

**Typography**: 
- Sans-serif headings: Off = monospace headings (the Opus signature). On = the body sans face.
- Body font: Reading-text font family. Leave blank for the theme default.
- Monospace font: Font for code and headings. Leave blank for the theme default.

**Features**: 
- Hide active-file rail: Removes the amber rail on the selected file in the sidebar.
- Hide active-tab rail: Removes the amber rail on the active editor tab.
- Flat code blocks: Removes the shadow and amber top-sheen from code blocks.
- Dark terminal code in Light mode: Keep code blocks dark even in light mode — the original signature look.

**Layout & motion**: 
- Heading rhythm: Vertical spacing unit between headings and body. Lower = denser, tighter documents. Default matches the v2.2 scale.
- Compact / density mode: Condensed operator profile — tightens body and heading line-height, list spacing and indent, callout padding, native and Dataview table cell padding, tab height, and heading margins. Off by default; changes nothing until enabled.
- Disable motion: Off = a single 130ms ease-out transition on the rails, hover, checkbox, callout fold, and link states (the v2.2 default). On = instant, no transitions. Reduced-motion is always respected regardless of this toggle.

**Measure**: 
- Readable line width: Max width of the reading column when Obsidian's "Readable line length" is on (Settings → Editor). Default 44rem matches the current column.
- Editor font size: Reading/editing text size in pixels.
- Line height: Body line spacing. Denser at 1.4, airier at 1.9.

**Table row states**: 
- Active-row glow: Accent tint intensity on the active (cursor) table row. 8% is the shipping default; 0 disables the accent glow (neutral hover + leading rail remain).
- **OLED and contrast**: 
    - OLED true black: Dark mode only. Forces the background to pure
    - Higher contrast: Dark mode only. Brightens ink and strengthens rules for low-light reading. Pairs well with OLED true black.

**Mobile**: Applies on phone and tablet only. Desktop is unaffected.
- Mobile text scale: Multiplies the reading/editing text size on mobile only. 1.0 = the Measure size as-is; nudge up for phone legibility.
- Dock keyboard toolbar: Off = the keyboard formatting toolbar floats as a rounded panel inset from the edges (default). On = it docks flush to the bottom edge.
- Lean mobile note header: Trims the per-note top header height on phones to reclaim vertical space. Off by default.
- Vivid canvas colors: Canvas only. Off = the muted, operator-grade 6-color set that harmonizes with the slate world (default). On = punchier versions of the three fixed hues (sage, slate-blue, plum) for higher separation on dense diagrams. The three semantic slots (clay/amber/teal) follow the flavor either way.
