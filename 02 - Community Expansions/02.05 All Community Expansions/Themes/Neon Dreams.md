## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**Colors**: 
- Base hue: Hue of the background color scale (0–360). Default: 231 (blue-black)
- Base saturation: Saturation of the background scale. Default: 30%
- Accent hue: Hue of the primary interactive accent (0–360). Default: 234 (indigo)
- Accent saturation: Saturation of the accent color. Default: 100%

**Editor**: 
- Active line highlight: Highlight the current line in the editor
- Hide markdown syntax: Hide formatting symbols in Live Preview
- Line numbers: Show line numbers in the editor gutter
- Code blocks scroll horizontally: Prevent code blocks from wrapping

**Interface**: 
- Hide ribbon: Show ribbon only on hover
- Minimal status bar: Reduce status bar visibility
- Disable animations: Remove all transitions and animations
- Fast animations: Speed up all transitions

**Content**: 
- Square checkboxes: Use square checkboxes instead of rounded
- Tags as plain text: Remove pill styling from tags
- Outlined callouts: Use border-only style instead of filled background
- Remove embed decorations: Hide embed borders and title

**Tables**: 
- Full-width tables: Tables fill the content column
- Wide tables: Tables extend beyond the text column
