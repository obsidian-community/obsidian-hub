## Customization Options (Style Settings Plugin) 

**Interface**: Choose the language used throughout Owen Graphite.
- Language: Follow Obsidian's language or override it for Owen Graphite Style Settings.

**Reading and body**: 
- Body font size: Base font size for body text such as paragraphs and list items.
- Body line height
- Maximum content width: Choose a reading width for long prose or a wider width for tables and reports.
- Heading accent color

**Tables and code**: 
- Prevent PDF block splitting: Reduces page breaks inside callouts, tables, Mermaid diagrams, code blocks, and images.

**Reports and PDF**: 
- PDF readability preset: Applies Pretendard, 36px titles, 18px subtitles, 16px body text, 14px captions, and 1.56 body line height without changing the selected PDF paper size.
- PDF font size: Adjusts body, list, callout, code, and header/footer label sizes without changing heading hierarchy or table design.
- PDF link output mode: Choose whether external URLs appear inline, stay hidden, or are organized around references in PDF exports.
- Serif body font: Switches body text to Noto Serif KR for long-report readability.
- First-line indentation: Applies a 1em first-line indent for Korean report styling.
- Automatic heading numbering (1. 1.1 1.1.1)
- Report heading design template: Applies the H1-H4 design to Live Preview and PDF output, grouped into standard, emphasis, and index families.
- Drop cap (enlarge first paragraph initial)
- Spacing preset
- Accent color preset
- Code block theme

**Workspace and accessibility**: 
- Eye-care mode (beige background)
- Follow OS dark mode automatically: Applies dark theme variables when the operating system uses dark mode.
- Desktop hover motion: Adjusts hover and press lift for buttons, menu items, and setting rows. Off preserves color and shadow feedback without movement.
- Automatic +0.5px Korean/CJK font adjustment

**Font application**: 
- Custom interface font: Leave empty to follow Obsidian's interface font. Example: "Malgun Gothic", Pretendard, sans-serif.
- Custom reading font: Leave empty to follow Obsidian's text font. Example: "Noto Serif KR", serif.
- Custom code font: Leave empty to follow Obsidian's monospace font. Example: "D2Coding", "JetBrains Mono", monospace.
- Custom status bar font: Leave empty to follow the interface font. Example: "Malgun Gothic", sans-serif.

**Small PDF header/footer labels**: Shows header and footer labels only in PDF output, not in on-screen Reading View.
- Show first-page header label: Shows one label at the top of the first PDF page. Turning this off hides it even when text or a preset is configured.
- Show last-page footer label: Shows one centered label below the final PDF content. Turning this off hides it even when text or a preset is configured.
- PDF label layout: Single label shows one phrase. Key/Value joins a pair such as `Prepared by` + `Owen Lee`.
- **Common configuration**: 
    - Header/footer quick text: Output combinations used when custom text is empty. Custom header or footer text takes precedence.
    - Header/footer text color: Shared text color for both labels. The default is a graphite tone suited to printed output.
    - Header/footer label style: Provides surfaces that remain stable in PDF engines without changing position or page flow.
    - Header/footer label size: Adjusts text and internal padding with two print-stable sizes.
- **Header settings**: 
    - Header key color: Color of the left key area in the first-page header, such as `Prepared by`.
    - Header value color: Color of the right value area in the first-page header, such as `Owen Lee - Sr. CSA`.
    - First-page header pair 1 key text: The full phrase in single-label layout or the left key in pair 1. Example: `Prepared by`.
    - First-page header pair 1 value text: The right value in pair 1, such as `Owen Lee` or `Sr. CSA`. Not used by single-label layout.
    - Show first-page header pair 2: Adds only the second key/value pair to the existing one-pair layout. Selecting `Two Key/Value pairs` in PDF label layout has the same effect.
    - Header pair 2 key color: Color of the second header key segment, such as `Reviewed by`.
    - Header pair 2 value color: Color of the second header value segment, such as `Graphite QA`.
    - First-page header pair 2 key text: The second key segment. Example: `Reviewed by`.
    - First-page header pair 2 value text: The second value segment. Example: `Design QA` or `2026-05-17`.
    - First-page header position: Choose the first-page header position. Key/value segments stay joined at the same anchor. The last-page footer remains fixed at bottom center for stability.
- **Footer settings**: 
    - Footer key color: Color of the left key segment in the last-page footer, such as `Confidential`.
    - Footer value color: Color of the right value segment in the last-page footer, such as `End of Document`.
    - Last-page footer key text: The full phrase in single-label layout or the left key in key/value layout. Example: `Confidential`.
    - Last-page footer value text: The right value in key/value layout, such as `Internal Use Only` or `End of Document`. Not used by single-label layout.
