## Customization Options (Style Settings Plugin) 

**Theme settings**: 
- None: Primary Simplified keeps Primary's warm visual language while exposing only theme-specific toggles and presets. Use Obsidian Settings -> Appearance for fonts, accent color, and editor font size.
- **Appearance**: 
    - Accent palette: Switches the accent and checked-checkbox color to a curated palette, in light and dark mode.
    - Layout density: Switches between comfortable and compact spacing for file explorer rows and body text line height.
    - Heading style: Switches the font size and weight scale used for H1-H6, in one preset.
    - Colorful headings: Uses the theme palette to color H1-H6 headings in reading and editing mode.
- **Motion and performance**: 
    - Reduce theme motion: Disables decorative tab, popup, and background animations without changing Obsidian's functional transitions.
    - Remove popup background blur: Removes background blur from Settings, Command Palette, Quick Switcher, and other popups.
- **Workspace**: 
    - Ribbon style
    - Status bar style
    - Status bar item visibility
- **Editor and notes**: 
    - Editor background
    - Highlight active line: Adds background color to the active editor line.
    - Show lines under titles: Adds a subtle horizontal line under H1 headings and the inline note title.
    - Remove link underline
    - Disable alternative checkboxes: Turns off the theme's default checkbox icons if you use your own CSS snippet.
    - Hide note embed title: Hide the note's title when embedding notes.
- **Folders and bookmarks**: 
    - Folder color preset: Applies folder and bookmark color treatment as one preset instead of separate low-level toggles.
    - Use folder icons as collapse indicators: Use folders as collapse indicators instead of chevrons.
