## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Glass blur strength: How strong the frosted-glass blur is on panels, menus and modals.
- Panel transparency: 0 = fully transparent panels, 1 = fully solid.
- Note transparency: Opacity of the note pane itself. 0 = fully transparent, 1 = solid.
- Plain headings: Turn OFF the willemstadt-style colour bars and use coloured text instead.
