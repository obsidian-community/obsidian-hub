## Customization Options (Style Settings Plugin) 

**Color**: 
- Plain headings: Turn off the H1–H6 spectrum ladder; headings use the body ink.
- No heading tint: Remove the fading background wash behind each heading.
- Plain folders: Turn off file-explorer folder tinting by nesting depth.
- Plain tags: Turn off per-tag hues; all tags use the teal accent.
- Plain horizontal rules: Render --- as a hairline instead of a spectrum gradient.
- Plain bold & italic: Turn off colored emphasis; bold and italic use the body ink.
- Show note title in the view header: Restore the note name above the note, next to the nav buttons.
- Show inline title: Restore the large note name at the top of the note body.
- Show folder breadcrumbs: Restore the truncated folder path (needs the view header title).
- Colorblind-safe ladder: Reorder the depth ladder to lead with blue and orange instead of red and green.

**Typography**: 
- Sans-serif body: Use the interface sans for note body text instead of the serif.
- Line width: Readable measure for note content.
