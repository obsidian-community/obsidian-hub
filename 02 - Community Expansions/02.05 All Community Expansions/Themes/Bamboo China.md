## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- None: 竹影 · 宣纸竹青 — 东方意境主题。白纸为心、黛青为框，10 套意境配色让每篇笔记都有自己的氛围。
- 意境配色: 在 10 套东方意境配色间切换（胭脂、青绿…）。选「主题原生」不加 class，即竹影·宣纸竹青默认配色。
- 禁用悬停功能区: 悬停功能区为主题内置的默认开启功能：隐藏左侧功能区，鼠标移至左侧边缘时浮现，左侧折叠按钮始终可见。开启此选项可禁用该功能（恢复常驻可见的左侧功能区）。
- 左对齐标签页

**桌面**: 
- 中间视图圆角: 单独调整主编辑区（中间视图）画布的圆角大小，不影响卡片与标签页圆角。0 = 直角，数值越大越圆润。
- 中间视图阴影: 调整主编辑区（中间视图）浮起卡片的投影强度。0 = 无阴影（贴合画布），1 = 主题默认，2 = 更明显的浮起感。
- 标题栏可见度: 鼠标未悬停时标题栏的透明度。0 = 完全隐藏，0.5 = 半透明，1 = 始终显示。
- 展开面板操作
- 展开侧边栏标签
- 展开状态栏
- 媒体原始尺寸

**编辑器**: 
- 隐藏活动行高亮
- 限制全宽元素
- 简约标签: 去除标签的背景色和边框，仅保留文字颜色。

**无障碍**: 
- 粗体字重: 调整粗体文字的粗细程度。300 = 纤细，600 = 明显。中文用户建议 400–500 以获得更清晰的标题层级。
- 正文行间距: 调整正文的行间距。1.6 = 紧凑，1.8 = 中文阅读标准，2.2 = 宽松。
- 减少动画效果: 减少界面动画效果。
- 入场动画速度: 调整面板、对话框等入场动画的速度倍率。0 = 无动画，1 = 主题默认，2 = 双倍速。
- 退场动画速度: 调整面板、对话框等退场动画的速度倍率。
- 标准字号: 关闭操作系统动态字号。
- 界面字号: 微调界面文字大小。
- 图标大小: 微调图标大小。
- 带下划线的链接: 始终为链接添加下划线以提高可读性。
- 高亮链接颜色: 提高链接文字的颜色对比度，在浅色背景下更醒目。
