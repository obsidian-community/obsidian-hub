## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**Headers underline**: 
- H1 header underline
- H2 header underline

**Headers colors**: 
    - **All headers**: 
        - All headers are the same color
        - Header color
    - **Particular headers**: These settings won't work if `All headers are the same color` is ON
        - H1 color
        - H2 color
        - H3 color
        - H4 color
        - H5 color
        - H6 color

**Kanban**: 
- Kanban variant: Variations of Kanban styles
- Minimal height for cards: All cards will have the same initial height
- Full height lists
