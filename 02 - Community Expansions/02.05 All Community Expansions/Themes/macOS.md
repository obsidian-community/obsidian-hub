## Customization Options (Style Settings Plugin) 

**Colors**: 
- Accent Color: Matches macOS system accent colors. Values shift between light and dark mode to match Apple's accessibility-adjusted palette.
- Accent Color (Dark Mode Override): Dark mode variant — Apple shifts accent colors brighter for contrast on dark surfaces.

**Typography**: 
- Monospace Font

**Appearance**: 
- Translucent Panels: Glass blur effect on sidebar and right panel. Disable for solid opaque panels.
- Glass Modals: Translucent modals, command palette, and menus. Disable for solid overlays.
- Full-Width Callouts: Callouts span the full editor width
- Colorful Headings: Tint each heading level with a different system color
- Accent Sidebar Icons: Tint sidebar and ribbon icons with the accent color, like macOS Finder
