- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**Layout**: 
- Note width: Controls the readable note width.
- Code block width: Controls the centered code block width.
- Hide decorative heading lines: Removes accent lines under H1 and H2 headings.
- Plain embeds: Removes Alice Velvet framing from embeds.

**Fonts**: 
- Title font
- Heading font
- Body font
- Accent font
