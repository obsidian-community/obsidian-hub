## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**Colors**: 
- Adaptive accent: Dynamically adapt the accent color based on the background color. Aims at having a better contrast for dark accent color in dark mode, or light accent color in light mode.
- Print with color scheme: Export notes to PDF using the current color scheme. This option doesn't synchronize with the current mode being used, you have to manually change it. Custom colors for dark mode won't work.
- Light color scheme: Select from a list of existing themes, or create your own by choosing custom
- Dark color scheme: Select from a list of existing themes, or create your own by choosing custom
- Opposite background: Enable to use a light (resp. dark) app background in dark (resp. light) mode.
- Custom - Primary: Color of the primary background (--color-base-00)
- Custom - Text: Color of the text (--color-base-100)
- Custom - Gradient color space: Color space used in the color-mix() function creating the palette. They all give different effects for the colors between the primary background and the text foreground.
- **Rainbow settings**: 
    - Rainbow text brightness
    - Rainbow text saturation
- **Note accent colors**: 
    - Note accent Color 1
    - Note accent Color 2
    - Note accent Color 3
    - Note accent Color 4
    - Note accent Color 5
    - Note accent Color 6

**Accessibility**: 
- Enable Accessibility variant: This option makes the vault easier to read, with sans serif fonts, and increased font size and weight.
- Background textures: Enable the background texture in the sidebars.
- Inline margin (left/right) for float elements: Float elements are, for example, the fas-infobox callout, the polaroid callout, floating images, etc.
- Scrollbars width
- Icon opacity in inactive tabs

**Workspace**: 
- Status bar position
- Ribbon position
- Left sidebar toggle button out of ribbon
- Vault menu at the top
- Show note header on hover
- Also crop the corners of the central pane
- Use a higher contrast for elements on the workspace background: Affects vault name, ribbon, tab names, etc.
- Never fade out elements on the workspace background: Affects vault name, ribbon, tab names, etc.
- Invert tab header colors: Use the primary background for the tabs, and the secondary background for the container
- **App background image**: 
    - Enable app background image
    - Image url
    - Blur
    - Opacity
    - Content opacity
- **File explorer**: 
    - Rainbow folders
    - Indentation for files and folders: Left indentation of each child of a folder in the File explorer and the Bookmarks tree
    - Vertical spacing for files titles: Padding of each file title in the File explorer and the Bookmarks tree
    - Vertical spacing for folders titles: Padding of each folder title in the File explorer and the Bookmarks tree
- **Sidebars**: 
    - Bookmark style for the tabs
    - Gap between the selected tab and the content in the sidebars: If you're annoyed by the fact that they touch each other, increase this value
    - Color of the inside border
    - Use custom sidebar texture
    - Sidebar texture url
    - Sidebar texture blending mode, in light mode
    - Sidebar texture blending mode, in dark mode
    - Sidebar texture size
    - Sidebar texture position
    - Sidebar texture opacity
    - Use custom file explorer decoration
    - File explorer decoration url
    - File explorer decoration blending mode, in light mode
    - File explorer decoration blending mode, in dark mode
    - File explorer decoration  size
    - File explorer decoration position
    - File explorer decoration opacity
    - Animate the hover effect in the file explorer

**Editor**: 
- File line width
- Compact mode: Enable to use a more compact layout in the editor, reducing multiple spacingg
- Highlight active note: Inspired by the plugin Limelight, code adapted by @tif
- **Background image**: 
    - Enable note background image for all notes: Use the cssclass "no-background" to disable in specific notes. If this option feature is disabled globally, you can use the cssclass "background-img" to enable it in specific notes.
    - Image url
    - Blend mode, light mode
    - Blend mode, dark mode
    - Repeat background image
    - Blur
    - Opacity
    - Brightness (light mode)
    - Brightness (dark mode)
    - Export to PDF: Use the note's background when exporting the note to PDF.
- **Banners**: 
    - Banner height
    - Banner slope angle
    - Banner width in print mode
    - Banner style in edit mode
- **Callouts**: 
    - Theme quote callout: Enable to use the Frozen Kingdom specific style for the quote and cite callouts (the style can still be used with `cite-fas` or `quote-fas` callout types if you keep this option disabled).
    - Use > [!infobox]: Enable the usage of `infobox` as an alias for `fas-infobox`
    - Minimize infobox in live preview: Enable to reduce the size of the `fas-infobox` callout in live preview mode when not hovering it.
    - Enable list callouts: Automatically inline any callout directly inside a list item
    - Default color for callouts
- **Code**: 
    - Limit code to 80 characterss: Use the standard brought to us by the IBM's 1928 punch card format and limit the number of characters to 80 for your code (only affects reading mode).
- **Headings**: 
    - Color for the headings
    - **First level headings (H1)**: 
        - Appearance
        - Color
        - Font size (em): Not affecting the Display appearance
        - Weight: Not affecting the Stroke appearance
        - Variant
        - Line height: Not affecting the Display appearance
        - Style
    - **Second level headings (H2)**: 
        - Appearance
        - Color
        - Font size (em): Not affecting the Display appearance
        - Weight: Not affecting the Stroke appearance
        - Variant
        - Line height: Not affecting the Display appearance
        - Style
    - **Third level headings (H3)**: 
        - Appearance
        - Color
        - Font size (em): Not affecting the Display appearance
        - Weight: Not affecting the Stroke appearance
        - Variant
        - Line height: Not affecting the Display appearance
        - Style
    - **Fourth level headings (H4)**: 
        - Appearance
        - Color
        - Font size (em): Not affecting the Display appearance
        - Weight: Not affecting the Stroke appearance
        - Variant
        - Line height: Not affecting the Display appearance
        - Style
    - **Fifth level headings (H5)**: 
        - Appearance
        - Color
        - Font size (em): Not affecting the Display appearance
        - Weight: Not affecting the Stroke appearance
        - Variant
        - Line height: Not affecting the Display appearance
        - Style
    - **Sixth level headings (H6)**: 
        - Appearance
        - Color
        - Font size (em): Not affecting the Display appearance
        - Weight: Not affecting the Stroke appearance
        - Variant
        - Line height: Not affecting the Display appearance
        - Style
    - **Headings Display settings**: 
        - Line height (em)
        - Text color
        - Background color
        - H1 size (em)
        - H2 size (em)
        - H3 size (em)
        - H4 size (em)
        - H5 size (em)
        - H6 size (em)
- **Horizontal rules (HR)**: 
    - Enable custom HR
    - Color
    - Ornament shape url: This image is used as a mask based on its alpha channel
    - Ornament size (em): Size of the ornament
    - Ornament right position (px): Space left at the right of the ornament
    - Ornament padding (px): Space between the ornament and the line, on its left and right
    - Ornament shadow size (px): Size of the fading gradient of the line when going behind the ornament
- **Images**: 
    - Shadow offset (px): Set to 0 for no shadow
    - Shadow stripe thickness (px)
    - Shadow stripe gap (px)
    - Center images: If enabled, the images will be centered if they are not in a paragraph (one empty line before and after)
- **Links**: 
    - Internal link decoration
    - External link decoration
- **Lists**: 
    - Bullet style
    - Checkbox style
    - Alternative checkboxes
    - Rainbow lists markers
    - List styling: Change the way bullet lists are displayed in reading mode.
    - Tree view/Bullet threading guide width
- **PDFs**: 
    - Blend mode, light mode: multiply mode suggested
    - Blend mode, dark mode: screen mode suggested, with "Invert in dark mode" enabled
    - Invert in dark mode
- **Properties**: 
    - Number of columns
    - Label width: The width of the properties labels (also called keys, or names)
- **Tables**: 
    - Table style
    - Table position
    - Wrap in source mode
- **Typography**: 
    - Bold text color
    - Italic text color
    - Highlight background color
    - Highlight text color
    - Pen highlighter effect

**Community plugins**: 
- **Fantasy Statblocks**: 
    - Change the style of Fantasy Statblocks
    - Accent color
    - Color for the art deco elements
    - Custom color for the art deco elements
    - Change the horizontal lines
    - Add file explorer icons for files and folders
    - Change the corners in the sidebars
    - Change the style of the sidebar tabs: The bookmark style for the tabs must be enabled
    - Add a decoration under the file header
    - Add a decoration in the left ribbon
    - Style the callouts
    - Change the sidebar textures
    - Style the properties
    - Style the list items bullets
    - Style the first headings: The style must be set to Display
    - Style the status bar
    - Add a special styling to empty spaces (when no file is open)
    - Style the tabs in the main space
    - Text color
    - Weight

**Additional content**: 
- Canvas node tags: Usage of tags to define specific styling for canvas card can be very powerful. However, it requires a code that can cause performance issues. Also, such styling come as independant snippets. You can add the file [canvas-node-bundle](https://github.com/ElsaTam/obsidian-frozen-kingdom/blob/main/snippets/canvas/canvas-node-bundle.css) to your [snippets folder](https://help.obsidian.md/Extending+Obsidian/CSS+snippets) to download all the effects. Or choose individual ones from [this list](https://github.com/ElsaTam/obsidian-frozen-kingdom/tree/main/snippets/canvas).
- Recursive rainbow folders: Files and subfolders inherit the color of their main folder.
