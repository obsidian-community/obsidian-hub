## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**Theme color**: 
- Background tint hue: Rotate the whole paper palette around the wheel — backgrounds, text and headings shift together, so the default green can become pink, purple, blue, and so on. Lightness and saturation stay fixed, so the vibe is preserved. The tan accent is left untouched.

**Layout & typography**: 
- Corner radius: Roundness of cards, buttons, tabs and inputs.
- Body font size
- Line height
- Reading line width: Maximum text width, in characters.
- Plain bold & italic: Turn off the orange tint on bold and italic text.
- Left-aligned body text: Disable justified paragraphs in reading view.
- Image shadow: Add a soft drop shadow under images in reading view.
- Highlight active line: Tint the line the cursor is on in the editor.

**Graph colors — Light mode**: 
- Node color
- Link color
- Tagged node color
- Unresolved node color

**Graph colors — Dark mode**: 
- Node color
- Link color
- Tagged node color
- Unresolved node color
