## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Select Workspace Layout: Choose between Default (flush) or Card (floating) layout.
- Enable Custom Left Panel Background: Adjust color and corner radius for the left sidebar.
- Left Panel Color
- Top Left Corner Radius
- Top Right Corner Radius
- Bottom Left Corner Radius
- Bottom Right Corner Radius
- Enable Custom Middle Panel Background: Adjust color and corner radius for the main editor.
- Middle Panel Color
- Top Left Corner Radius
- Top Right Corner Radius
- Bottom Left Corner Radius
- Bottom Right Corner Radius
- Enable Custom Right Panel Background: Adjust color and corner radius for the right sidebar.
- Right Panel Color
- Top Left Corner Radius
- Top Right Corner Radius
- Bottom Left Corner Radius
- Bottom Right Corner Radius
- Enable Custom Active Tab Background
- Active Tab Color
- Enable Custom Vault Profile Background: Adjust color and corner radius for the vault profile.
- Vault Profile Color
- Top Left Corner Radius
- Top Right Corner Radius
- Bottom Left Corner Radius
- Bottom Right Corner Radius
- Enable Panel Borders: Apply custom borders to the Left, Middle, Right, and Vault Profile panels.
- Panel Border Thickness
- Panel Border Color
- Panel Border Style
- Panel Border Radius
- Inner Panel Gap: Spacing BETWEEN the left, middle, and right panels.
- Right Edge Gap: Spacing on the far RIGHT edge of the window.
- Bottom Edge Gap: Spacing on the far BOTTOM edge of the window.
- Enable Custom Card Background: Override the default background color and opacity for Card Layout.
- Card Background Color
