## Customization Options (Style Settings Plugin) 

**Typography**: 
- Monospace note font: Render notes in your configured monospace font for a typewriter-style editing feel.
- Disable comment italics: Render code-comment italics upright. Mirrors the VS Code hearthcode.disableItalics option and helps CJK fonts that fake-oblique instead of slanting.
- Readable line length: Column width for readable line length, in rem. Applies when the Readable line length setting is enabled.

**Callouts**: 
- Callout background: How strongly callout backgrounds are tinted. Quiet is subtle; bold is more saturated. Medium is the theme default.

**Accent**: 
- Accent color: Swap the accent (links, active controls, buttons) for a contrast-vetted preset. Moss is the default sage; Amber is warm; Slate is cool. Every preset keeps button and link text at AA 4.5:1.
