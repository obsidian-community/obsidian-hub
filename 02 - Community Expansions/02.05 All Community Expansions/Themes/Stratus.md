- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**Typography and layout**: 
- Reading width: Requires Settings → Editor → Readable line length. Note cssclasses `wide` / `max` still override per file.
- Custom line width: Optional fine control. Leave untouched to use the Reading width preset above.
- Editor text size
- Interface density: Spacing for sidebars, tabs, and lists.

**Appearance**: 
- Accent color: Cloudflare orange (default) or console blue.
- Disable active editor line highlight
- Emphasize properties block: Off keeps properties quieter (Stratus default). On restores a stronger bordered block.

**Focus mode**: 
- Hide ribbon
- Hide status bar
- Hide tab bar
- Hide properties in Reading view
- Hide inline title
