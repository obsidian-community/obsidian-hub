## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Background contrast
- Callout style
- Show properties heading
- Show "Add property" button
- Disable active line highlight
- Disable title underline: Remove the divider below the note title and H1 headings
- Disable link underlines
- Disable colorful headings: Remove unique colors from heading levels H1–H6
- Disable custom task icons: Turn off Praxis custom icons for task checkboxes. Useful when using a custom CSS snippet for task states.
