## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Framer Design System: A clean theme inspired by Framer's design system, with pink accents (dark) and rose gold accents (light), and smooth transitions.

**Appearance**: 
- Interface Font: Font used for the UI
- Accent Style

**Animations**: 
- Reduce Motion: Disable smooth transitions

**Features**: 
- Quick Actions Style: Enhanced command palette with Framer Quick Actions look
- Plain Headings (需要 Style Settings 插件): 勾选后将彩色标题恢复为正文色

**Maintenance Controls**: 
- Use Native Borders: Disable Framer's broad borderless UI patch when an Obsidian or plugin update makes boundaries unclear.
- Simple Motion: Keep basic transitions but disable the richer tab, modal, icon, and folder animations.
- Dock Status Bar: Disable the floating status bar behavior and use Obsidian's native status bar placement.
- Disable Editing Toolbar Patch: Turn off Framer's Editing Toolbar compatibility patch if the plugin changes its CSS.

**Plugins**: 
- Dataview Styling: Apply Framer styling to Dataview tables
- Kanban Styling: Apply Framer styling to Kanban boards
- Calendar Styling: Apply Framer styling to Calendar plugin

**Mobile**: 
- Mobile Adaptation: Apply 13px panel text and 44px touch targets on mobile

**Editor**: 
- Reading Mode Prose: Optimize reading mode with max-width and comfortable spacing
- Code Panel Line Numbers: Style editor line numbers like Framer code panel

**Snippets**: 
- Bold Pink: Make bold text pink (#FF69B4) in reading and live preview. Built-in, always active.
- Immersive Translate Red Gradient: Apply red gradient to Immersive Translate plugin results. Built-in, always active.
- Minimal Tables: Full-width tables with auto layout and minimal borders. Built-in, always active.
- Floating Status Bar: Status bar slides in from the right on hover. Built-in, always active.
