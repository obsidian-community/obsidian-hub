## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Theme color: Select your desired color for the theme.
- Pure black background: Use a pure black background. Great for OLED screens.
- Inverted table style: Use an inverted style for tables.
- Retro emphasis mode: In Reading view, bolded text and table headers will become ALL CAPS text instead. Does not affect editing view.

**Theme Fonts**: 
- Main font: Select a suitably sci-fi font for most text.
- Title font: Select a font to be used for note titles.

**Contrast Controls**: 
- Boxed Callout: Use an empty box for callouts instead of a card.
- Brighter table text: Use a different color for text inside tables.
- Brighten bold and italic text: Use a brighter color for bolded and italicized text. Makes them pop. Useful for finding things at a glance.
- Brighten all text: For extra contrast across the board. Overrides the "bold and italic" option above.
