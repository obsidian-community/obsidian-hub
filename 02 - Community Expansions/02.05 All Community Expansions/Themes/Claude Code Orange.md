## Customization Options (Style Settings Plugin) 

**Typography**: 
- Serif reading mode: Use a Tiempos-style serif for note body text, like Claude's serif reading mode. Headings and the interface stay sans.
- Serif headings: Render headings in the serif as well (pairs nicely with serif reading mode).
- Body font size (px): Base font size for note text.
- Line height: Body line height.
- Readable line length (rem): Maximum width of note text when a line-length limit is active (Obsidian's "Readable line length" or the toggle below).
- Limit line length: Keep note text at a readable width even when Obsidian's "Readable line length" setting is off.
- File & folder name size (px): Font size for names in the file explorer.
- Folder name weight: Weight of folder names in the file explorer.
- File name weight: Weight of file names in the file explorer.

**Color**: 
- Accent color (light mode): The Claude coral. Drives links, active elements and highlights.
- Accent color (dark mode): The Claude coral for dark mode.
- Loud code blocks: On — code blocks use a blue frame so they stand out. Off — code blocks stay warm, in line with the Claude coral theme.
- Monospace headings: Give headings a terminal / code feel by setting them in the monospace font.

**Light mode tuning**: 
- Text darkness (%): Black mixed into light-mode body text. 0 = original warm ink, higher = darker and stronger.
- Text weight: Light-mode body font weight. Needs a variable font — the bundled Hanken Grotesk and Source Serif 4 both are; static fonts round to the nearest weight.
- Background depth (%): Black mixed into the light-mode backgrounds. 0 = default warm cream, higher = deeper paper. All light surfaces deepen together so their hierarchy is preserved.

**Dark mode tuning**: 
- Text brightness (%): White mixed into dark-mode body text. 0 = original warm off-white, higher = brighter.
- Text weight: Dark-mode body font weight. Needs a variable font — the bundled Hanken Grotesk and Source Serif 4 both are; static fonts round to the nearest weight.
- Background darkness (%): Black mixed into the dark-mode backgrounds. 0 = default warm charcoal, higher = deeper. Raises contrast without making the text glow.

**Editor**: 
- Highlight active line: Add a very light tint behind the line your cursor is currently on in the editor.
- Scroll progress bar: A thin coral bar across the top of the note (bottom of the screen on mobile) showing how far you've scrolled. Pure CSS — pairs with the Claude Scroll Map companion plugin for clickable heading dots.

**Plugins**: 
- Sticky headings in the title bar: With the "Another Sticky Headings" plugin, show the heading trail as a clickable breadcrumb in the note title bar (replacing the note title while you're scrolled into a section) instead of a block above the note. Desktop only — on mobile the plugin keeps its regular stacked view. No effect if the plugin isn't installed.
