## Customization Options (Style Settings Plugin) 

**Window Settings**: Adjust the window settings. Affects all parts except the editor area.
- Brightness of window.: Adjust the brightness of the entire form。
- Adjust the font of the Window.: Adjust the font size of some parts, including the document directory on the left, the document title on the top, the outline directory on the right, the tag list, and so on.
- Close left vault profile.: Switch the vault profile to the default bottom.

**Editor Settings**: Adjust the editor settings. Affects only the editor area.
- Hide the Heading prompt in the editor.: Hide the h1...h2... and other small title prompts in front of headings at all levels.
- Hide the Heading bottom line in the editor.: Hide the h1...h2... and other small title bottom line in headings at all levels.
- Open text justification.: Default text is left-aligned. If it is turned on, it is justified.
- Adjust the width of the editor.: Adjust the editor width. The default is 800. The minimum is 500 and the maximum is 2000.
- The gap of the text paragraph.: Adjust the gap of the text paragraph.
- The height of the text line.: Adjust the height of the text line.
- Brightness of editor.: Adjust the brightness of the middle editor area.

**Windows/Linux**: Only valid for Windows/Linux.
- Close the translucent window.: Turn off the window translucency of Windows/Linux. It is only effective for Windows/Linux.
- Transparency of window background: Adjust the transparency of the form background on the Windows/Linux platform. Only effective for Windows/Linux. Recommended values：For dark colors：0.2. For light colors：0.15.
- Brightness of form background.: Adjust the brightness of the form background on the Windows/Linux platform. Only effective for Windows/Linux. Recommended values：0.9.
- the background picture of the window: Set the form background image; fill the image URL between the quotes; leave blank for no background image by default.
- Adjust the color of the middle editing area.

**macOS**: Only valid for macOS.
- MacOS：The transparency of the window background.: Adjust the transparency of the window background on the Mac platform. Only effective for macOS, and the translucent effect switch is turned on in Settings -> Appearance.
- Adjust the color of the middle editing area.
