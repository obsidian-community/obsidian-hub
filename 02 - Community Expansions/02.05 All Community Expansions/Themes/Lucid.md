## Customization Options (Style Settings Plugin) 
- Lucid: Obsidian Glass palette (violet + teal). All colors, fonts and layout below drive the whole theme and its custom features.

**🎨 Colors**: 
- Primary accent: Blue by default. Drives links, active states, glows.
- Secondary accent: Teal by default. Used in gradients and hover links.
- Folder / highlight gold
- Danger / close
- App background (deepest)
- Editor / note background
- Sidebar background
- Card / raised panel background
- Body text
- Headings / strong text
- Muted text
- Faint text / icons
- Inline code color
- **Tag & graph colors**: 
    - Tag tint — blue (cloud / platform)
    - Tag tint — green (data / pipeline)
    - Tag tint — amber (storage / db)
    - Tag tint — rose (people / meta)
    - Graph node color
    - Graph edge color

**✒️ Typography**: 
- Use system fonts: Skip the bundled Google fonts (faster / offline / mobile).
- Body & interface font: Pick from common system fonts.
- Heading / display font: Pick from common system fonts.
- Monospace / label font: Pick from common system fonts.
- Note width (readable line length)
- Body font size
- Line height
- Bold weight
- Sidebar font size
- **Heading sizes & weight**: 
    - Inline title size
    - H1 size
    - H2 size
    - H3 size
    - H4 size
    - H5 size
    - H6 size
    - Heading weight
- **Heading colors (H1–H6)**: Color-coded headings, like the vault snippet.
    - H1 color
    - H2 color
    - H3 color
    - H4 color
    - H5 color
    - H6 color
- **Text format colors**: Bold / italic / strikethrough.
    - Bold color
    - Italic / emphasis color: Teal by default — different from the blue accent. Also colors *em* in headings & cards.
    - Bold + italic color
    - Strikethrough color

**🗨️ Callout colors**: One accent per callout type. Same syntax as ITS: > [!tip], > [!warning], etc.
- Note / info / summary / abstract
- Tip / success / important / done
- Warning / caution / attention
- Question / help / FAQ
- Failure / danger / error / bug
- Example
- Quote / cite

**🟦 Shape & motion**: 
- Roundness
- Scrollbar width
- Disable animations: Turn off entrance + hover motion (also respects OS reduced-motion).
- Heading underline width
- Disable heading underline
- Accent background glow (Glass wash): Re-adds the soft violet glow behind the app. Off = flat near-black like the reference.

**✒️ Editorial & polish**: 
- Editorial drop cap: Large serif initial on the first paragraph of a note (reading view + live preview).
- Drop cap size
- Solid drop cap (no gradient): Fill the drop cap with a flat accent color instead of the violet→teal gradient.
- Quote mark opacity: Strength of the oversized quotation mark behind blockquotes.
- Divider gem size: Size of the diamond ornament in the center of "---" dividers.
- Heading letter spacing
- Paragraph spacing: Vertical gap below each paragraph.
- Default heading alignment: Aligns all headings (both views). Per-heading "#center /
- Highlight active line (editor): Faint accent wash behind the line your cursor is on, in live preview / source.
- Scroll reveal: Headings, callouts, tables and quotes fade-rise as they scroll into view (native, no JS).
- Decorative quote mark: Oversized serif quotation mark behind blockquotes and pull quotes.
- Plain dividers (no gem): Removes the center diamond ornament from "---" dividers, leaving just the fading line.
- Heading underline fits text: Heading boxes (and their underline) shrink to the text width instead of spanning the full column. Off = full-width underline.

**🧩 Custom features**: 
- Multi-column — min sub-callout width
- Multi-column — gap
- Float callout width — small
- Float callout width — medium
- Float callout width — large
- Image border radius
- Gallery image max height
- Gallery image max width
- Gallery gap
- Banner height — normal
- Banner height — tall
- Enable image zoom via CSS
- Disable image sizing inside lists

**🃏 Cards (shared with Atelier)**: 
- Default card style: Style for a bare > [!card]. Override inline e.g. > [!card|profile] or > [!card|honor]. Add surfaces (dark / accent) and spans (span2 / spanfull). Wrap in > [!grid] to flow into columns.
- Card grid — min card width: Cards inside > [!grid] flow into as many columns as fit at this minimum width.
- Card glass blur: Backdrop-blur strength on frosted cards & infobox (0 = flat / opaque-ish).

**🌈 Gradient text (.at-gradient)**: Colors for the Apple-style gradient text class. Use <span class="at-gradient">…</span>.
- Gradient stop 1
- Gradient stop 2
- Gradient stop 3
- Gradient stop 4
- Gradient angle
