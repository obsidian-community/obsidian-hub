## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Use fully black background on Phones and Tablets: Replaces standard dark blue backgrounds on mobile devices, saving some battery on OLED screens as a bonus.
- Tab close button on the left: MacOS users can enjoy familar placement of the Tab Close button.
- Paint folders orange: Apply awesome orange accent color to folders in the File Tree.
- Fancy thin font in headers: This makes Headers use thinner font for more classy look.
- Remove accent colors from links and mark them in bold: This gives calmer look to notes, especially with big amounts of links in them.
- Hide Bases Labels: Remove property labels from Bases Cards view.
