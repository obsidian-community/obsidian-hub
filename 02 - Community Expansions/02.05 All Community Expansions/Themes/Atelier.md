## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Atelier: 18th-c excavation-journal aesthetic — Excavation (dark) / Parchment (light), copper accent, IM Fell English + Spectral + Caveat. Colors, fonts, layout, animations and the per-element style variants below drive the whole theme.

**🎨 Colors**: 
- Primary accent: Coral by default. Drives links, labels, active states.
- Secondary accent: Deeper terracotta. Used in gradients and hover links.
- Folder / highlight gold
- Danger / close
- App background (deepest)
- Editor / note background
- Sidebar background
- Card / raised panel background
- Dark card surface (honor / CTA cards): Used by card v4 / v5; intentionally dark in both light and dark mode.
- Body text
- Headings / strong text
- Muted text

**🔤 Fonts & typography**: 
- Use system fonts: Skip the bundled Google fonts (faster / offline / mobile).
- Body & interface font: Pick from common system fonts.
- Heading / display font: Pick from common system fonts.
- Monospace / label font: Pick from common system fonts.
- Note width (readable line length)
- Body font size
- Line height
- Bold weight
- Sidebar font size
- Inline title size
- H1 size
- H2 size
- H3 size

**🧩 Element style variants**: 
- Default card style: Style for a bare > [!card]. Override any card inline, e.g. > [!card|profile] or > [!card|honor]. Combine surfaces (dark / accent) and spans (span2 / spanfull). Wrap cards in > [!grid] to flow them into columns.
- Card grid — min card width: Cards inside > [!grid] flow into as many columns as fit at this minimum width.
- Default infobox style: Style for a bare > [!infobox]. Override inline with |v1 … |v3. Add |left to float left.
- Tag style: How
- Paper texture (background): Ancient-paper backdrop for reading view. Painted behind the text (readability untouched) as a fixed, stationary field. Light + dark.
- Heading style: Decoration for h1–h3. Italic words inside headings always show the coral emphasis.

**✒️ Editorial & polish**: 
- Heading letter spacing
- Paragraph spacing
- Corner radius
- Default heading alignment: Per-heading "#center /

**📐 Density**: 
- Condense UI: Tighten spacing across the whole app — sidebar rows, file tree, note list, tabs, properties, callouts, lists, tables and paragraph rhythm. Good for laptops or dense vaults.
- Condense reading / editor too: Also tightens note body line-height, heading margins and block spacing (not just chrome). Requires Condense UI on.

**⚙️ Features & motion**: 
- Disable animations: Turn off entrance + hover motion (also respects OS reduced-motion).
- Opening animation: How each note's blocks enter when you open it. "Varied" cycles all three.
- Vault opening animation: A one-time reveal when the vault first opens (and on reload). The whole workspace animates in once — separate from the per-note opening animation above.
- Scroll reveal: Headings, callouts and quotes fade-rise as they scroll into view.
- Highlight active line (editor)
- Infobox width
- Multi-column — min sub-callout width
- Gradient-text color (.at-gradient): The .at-gradient class is a single accent colour here (it's a gradient in MyWiki Glass). Use <span class="at-gradient">…</span>.
