## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**Layout**: 
- Note width: sets the centered reading and editing width for normal notes.
- Code block width: sets a separate centered width for fenced code examples.
- Table size: keeps normal Obsidian table sizing by default, or applies a centered width preset.
- Hide decorative heading lines: turns off the red/blue heading rules when you want quieter notes.
- Plain embeds: removes the themed frame from embedded notes and files.

**Dark Mode**: 
- Dark background color: switches the dark mode app background between navy and a lighter deep blue.

**Fonts**: 
- Title font
- Heading font
- Body font
- Accent font
