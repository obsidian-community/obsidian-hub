## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- Monochrome links: When enabled, external links and underlines use the text color instead of  the accent color
- External link icon: Icon shown after external links (recommend setting when monochrome links are enabled)
- Adjust Readable line width: Settings → Editor → 'Readable line length' must be enabled foa any effect; (px)
- Blockquote border thickness: Thickness of left border for blockquotes (px)
- Completed task decoration: Completed task text is muted; also apply this decoration
- Opacity of images in dark mode
- Font for 'Source mode' view: Override the font used in 'Source mode' (defaults to 'SF Mono')
- Font for monospace content (code, preformatted) in 'Source mode' view: Override the font used in 'Source mode' monospace content (defaults to 'SF Mono')
- In 'Reading view', always use 'reader' style (serif fonts): Wnen enabled, to restore the default reading view for a note, add `no-reader` to its cssclasses property
- Don't shade table header row: Table header row is shaded by default
- Don't style Bases tables: Render embedded Bases tables like regular tables by default
- Don't hang heading characters in margin (source mode): Heading characters '###' hang in the margin (requires 'Readable line length')
- Don't add a heading '#' to inline title (source mode): Prefix Inline title with '#' and hang in the margin
