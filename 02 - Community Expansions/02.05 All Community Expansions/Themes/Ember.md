## Customization Options (Style Settings Plugin) 

**Accent**: 
- Accent colour: Drives links and interactive elements, and sets the HSL hue/saturation/lightness the rest of the theme derives from. Defaults differ per mode — amber in dark, deep ember in light.
- UI tint (hue): Warm neutral hue for backgrounds, text and surfaces. Rotate to retint the whole interface.

**Colour scheme**: 
- Palette: Swap the whole palette. Ember is the default warm scheme.
- True black background (OLED): Pure-black backgrounds in dark mode for OLED screens.

**Typography**: 
- Recommended fonts: Ember uses your system fonts by default. For the designed look, install Hanken Grotesk (body), Bricolage Grotesque (headings) and JetBrains Mono (code) — see the README — then enter their names below.
- Text / UI font
- Heading font
- Monospace font
- Code ligatures: Enable programming ligatures in code (needs a ligature font such as JetBrains Mono or Fira Code).
- Old-style figures: Use old-style (text) numerals in body copy where the font supports them.
- Dyslexia-friendly font: Switch body and headings to OpenDyslexic (must be installed locally).

**Reading**: 
- Reading measure (max line width): Maximum width of the text column (applies with Readable line length enabled).
- Density: Comfortable spacing, or a tighter compact layout.

**Elements**: Toggle individual styled components. Some are scaffolded and take effect as their styling lands.
- Tinted callouts
- Custom task states
- Styled tables
- Tags as pills
- Styled code blocks
- Styled embeds
- List relationship lines
- Dashboard tiles: Card/pill styling for notes with the `dashboard` cssclass. Layout applies regardless; this toggles the decorative look. Adapted from TfT Hacker.

**Properties**: Styling for the frontmatter / properties block at the top of notes.
- Style properties: Master toggle for all properties-block styling.
- Property key colour: Colour of the property name labels.
- Property field accent: Base accent for property icons and value highlights. Per-type field colours derive from the palette.
- Banner image: Show a banner above the properties block, driven by --ember-banner-image (see README; depends on your banner convention). Off by default.

**Accessibility**: 
- Reduce motion: Disable theme transitions and animations.
