## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 

**背景光晕**: 
- 光晕配色: 选择背景光晕的色彩主题。
- 光晕模糊 (px): 越大越柔和晕染
- 光晕强度

**界面行为**: 
- 自动隐藏侧边工具栏: 完全收起左侧工具栏（不留位），鼠标移到左边缘时丝滑滑出并推开内容。

**论文排版**: 
- 正文使用衬线字体: 关闭时使用系统自定义字体。开启才使用衬线。
- 两端对齐
- 段首 2em 缩进
- 首段首字母下沉
- 行距
- 正文最大宽度 (ch)
