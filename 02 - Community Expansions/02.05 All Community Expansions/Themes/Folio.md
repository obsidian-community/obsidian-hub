## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- 强调色（Accent / Clay）: 主强调色。改动会联动 checkbox、滑块、active 图标、链接高亮等所有引用 --interactive-accent 的组件。hover 态等派生色不联动。
- Inline Title 字号
- H1 字号
- H2 字号
- H3 字号
- 小圆角（inline code / 小元素）
- 中圆角（按钮 / 输入框 / 代码块）
- 大圆角（卡片 / 模态框 / 嵌入）
- Callout Info（Sky）
- Callout Warning（Kraft）
- Callout Error（Fig）
- Callout Success（Olive）
- Callout Clay
- Callout Slate
- Callout Heather
- 段落间距
- 列表项间距
- 表格水平内边距
- 表格垂直内边距
