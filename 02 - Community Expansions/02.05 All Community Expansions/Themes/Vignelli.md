## Customization Options (Style Settings Plugin) 

**Typography**: 
- Display font (headings): The Didone serif for headings — matches the Vignelli doc engine (Bodoni MT, ships with Office/Windows).
- Body font
- Monospace font
- Body font size
- Body line height
- Reading line width: Editorial measure — keep it near 40rem so lines stay ~66 characters.
- Note title size: The big title at the top of each note.
- Sidebar font size: Left menu / file-explorer text size.

**Palette**: 
- Gold (headers, dividers, table bars)
- Highlight colour (marks & selection)
- Ink headings (gold rules only): Turn on for bone/ink heading text instead of gold; the gold rules stay either way.

**Behaviour**: 
- Uppercase H1 (masthead): Set the top heading in spaced small-caps, like a document masthead.
- Justify body text
- Hide inline title: Hide Obsidian's filename title so a leading H1 is the sole masthead.
