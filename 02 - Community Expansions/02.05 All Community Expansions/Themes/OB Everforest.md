## Features

- [[Themes with Friendly Settings|Friendly settings]]: Supports the [[obsidian-style-settings|Style Settings]] plugin

## Customization Options (Style Settings Plugin) 
- None: Everforest color scheme over Baseline's native-style UI. Forked from [Cupertino](https://github.com/aaaaalexis/obsidian-baseline).
- Tinted sidebar: Apply a subtle tint to the sidebar based on accent color.
- Disable adaptive mode: Prevent automatic styling based on operating system.
- Disable centered tabs

**Desktop**: 
- Hover ribbon: Reveal ribbon by hovering over left window edge.
- Hover sidebar: Reveal collapsed sidebars by hovering over window edges.
- Focus view: Hide tabs and table title bar when both sidebars are collapsed.
- Disable compact panel actions
- Disable compact sidebar tabs
- Disable compact status bar
- Disable media zoom

**Editor**: 
- Disable active line highlight
- Disable banner
- Disable block width
- Disable font variants
- Disable full-width elements
- Disable quick mode switcher

**Accessibility**: 
- Reduce contrast change: Minimize contrast shifts when window loses focus.
- Reduce motion: Minimize animation effects.
- Standard font size: Disable operating system-based dynamic font sizes.
- Interface font size: Fine-tune interface text size.
- Icon size: Fine-tune icon size.
- Underlined links: Always underline links for improved visibility.
